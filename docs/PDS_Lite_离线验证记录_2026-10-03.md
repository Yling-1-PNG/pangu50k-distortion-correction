## HMIC 安装后的复测（2026-10-03）

用户在 PDS Lite GUI 中安装 `.iar` 后，本机确认 `D:\PDS_lite\PDS_2022.2-SP1-Lite\ip\system_ip\ipsxb_hmic_s\ipsxb_hmic_eval\ipsxb_hmic_s` 已出现。重新从原始 RAR 解出一份 `build\legacy_camera_after_ip\10_HDMI_DDR3_OV5640_test`，没有覆盖安装前的失败副本，也没有修改原始资料包。

| 操作 | 实测结果 | 证据 |
|---|---|---|
| `ip_generate.exe -i source\rtl\DDR3_50H\DDR3_50H.idf -verbose` | **通过**：Pango DDR3 Interface 1.4、PGL50H/-6/FBG484，66 个综合源文件，`Action 'synthesize': finished normally`，`Done: 0 error(s), 0 warning(s)`。复制副本的 `.idf` 生成器版本更新为 2022.2-SP1-Lite build 132640。 | `build\legacy_camera_after_ip\ddr_ip_generate_console.log` 与副本 `.idf`。 |
| `pds_shell.exe -project HDMI_DDR3_OV5640_test.pds -run compile` | **通过**，`Process "Compile" done.`。原来的加密模块未定义错误消失。 | `build\legacy_camera_after_ip\compile_console.log`。 |
| `pds_shell.exe -project HDMI_DDR3_OV5640_test.pds -run gen_bit_stream` | **通过**，日志明确写 `placed and routed successfully` 与 `Generate programming file done.`；产生 `generate_bitstream\hdmi_ddr_ov5640_top.sbit`，2,101,696 B。 | `build\legacy_camera_after_ip\bitstream_console.log` 与生成文件。 |

**不能把上述成功解释成 720p30 已在板上跑通或时序完全正确。** `report_timing\run.log` 有 178 条 `not constrained` 警告，包括相机 I²C 与 DDR 数据 IO。更值得先修的是副本 `source\rtl\pll\pll.idf` 中 `CLKOUT0_REQ_FREQ_basicPage=37.1250 MHz`、top 源码注释 `pix_clk //37.125M 720P30`，但官方 `hdmi_ddr_ov5640_top.fdc` 的 `create_generated_clock -name pix_clk ... -multiply_by 27 -divide_by 20` 在 50 MHz `sys_clk` 下给出 **67.5 MHz**；PDS 报告也按 67.5 MHz 分析。两者矛盾，需按实际 PLL 输出和 HDMI 时序重新核约束，不能以 `All Constraints Met` 判定视频帧率。另须核对 LED 管脚示例中的 VCCIO 差异、IO bank 实际供电和相机连接器，再考虑下载到板上。

当前软件层结论：Lite 支持该官方参考视频通路的 IP 生成和全流程构建；**不需要为了旧示例能编译而立刻装正式版**。赛题所需的畸变映射、双线性取样、动态角度与图像增强仍未实现，现有例程只是传输基线。
